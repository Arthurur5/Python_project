# Python_project

Тема: консольный менеджер задач в терминале

Ссылка: https://github.com/Arthurur5/Python_project

Фичи 1: добавление, удаление, редактирование и просмотр задач

Фичи 2: сортировка, задачи с дедлайнами

Библиотека: rich

Как запустить проект:
1. Клонировать репозиторий
2. pip3 install -r requirements.txt
3. python3 main.py

- show показывает таблицу с задачами
- add добавляет задачу
- delete удаляет задачу
- check изменяет статус задачи
- change изменяет задачу
- clear_done удаляет все выполненные задачи
- stop завершает работу
